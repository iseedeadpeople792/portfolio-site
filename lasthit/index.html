Сколько ударов до добивания, прямо над полоской

Программа смотрит на картинку игры, находит полоски здоровья крипов и показывает число ударов. Когда добить можно одним ударом, полоска подсвечивается зелёным.

Только смотрит на картинку: не читает память игры, не внедряется в процесс, ничего не нажимает за игрока.

Как это работает

  1. Захват окнаКадры берутся из окна игры через Windows Graphics Capture.
  2. Поиск полосокПолоски находятся по форме: рамка и ровная заливка.
  3. Чтение уронаУрон героя читается с панели встроенным OCR Windows, разброс берётся из базы героев.
  4. ОтслеживаниеПолоски сопровождаются между кадрами, поэтому подсказки не дёргаются.
  5. ОверлейПрозрачное окно поверх игры рисует число ударов над каждой полоской.

Допущения

Полоска показывает только долю здоровья, а ближний и дальний крип выглядят одинаково. Поэтому число ударов считается для обоих типов и показывается диапазоном. Зелёным полоска становится, только если добивание гарантировано для обоих.

Ограничения

Игра должна быть в оконном режиме или «окно без рамки» и быть активным окном. В эксклюзивном полноэкранном режиме оверлей показать нельзя.
