Длинная ссылка внутри, короткая снаружи

Сокращатель без сервера и базы данных: одна функция на Cloudflare Workers и хранилище KV. Бесплатный тариф.

Попробовать Код на GitHub

Что происходит с запросом

  1. POST /apiКлиент отправляет ссылку в JSON.
  2. ПроверкаПропускаются только http и https: ссылки javascript: и file: отклоняются.
  3. Код из шести знаковАлфавит без похожих символов. При совпадении берётся другой код, до пяти попыток.
  4. Запись в KVПара «код → ссылка» сохраняется в хранилище Cloudflare.
  5. GET /кодВоркер находит ссылку и отвечает 302. Неизвестный код получает 404.

Попробуйте проверку и генерацию

Страница выполняет ту же проверку и тот же генератор кодов, что воркер. Ссылки здесь никуда не сохраняются: это демонстрация в браузере.

Что учтено
Только http и https, код без 0/O и 1/l/I, понятная ошибка 400 на неверный JSON и на непрошедшую проверку ссылку.

    
Ограничения
Нет авторизации и лимитов на создание ссылок, поэтому для публичного использования нужно добавить ограничение запросов.

    
Проверка
Тест прогоняет создание, переход 302, ответ 404 и две ошибки 400 на поддельном хранилище.
