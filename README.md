# portfolio-site

Портфолио Даниила Плотникова: прокручиваемая история с анимацией на GSAP.

## Что внутри
- **Заставка:** буквы имени поднимаются из-под маски (SplitText), светящееся пятно догоняет курсор.
- **Текст-манифест:** слова проявляются вместе с прокруткой.
- **Проекты:** секция закрепляется, вертикальная прокрутка двигает ленту карточек вбок (ScrollTrigger + `containerAnimation`), внутри карточек параллакс.
- **Как я работаю:** закреплённая секция, линия дорисовывается, шаги загораются по очереди.
- **Контакты:** кнопка притягивается к курсору.

## Сайты проектов
- `lasthit/` — помощник добивания в Dota 2: заставка с живой подсказкой, закреплённая схема из пяти шагов, калькулятор с той же формулой брони, что в программе (`lasthit/calc.js`, тесты `npm test`).
- `stats/` — Dota 2 Статистика: окно приложения с графиками, закреплённый показ пяти вкладок, счётчики. Интерфейс на странице иллюстративный, данные условные.

- `shortener/` — сокращатель ссылок: схлопывающаяся ссылка в заставке, закреплённая схема пути запроса, демонстрация с настоящей проверкой http(s) и генератором кодов (`shortener/code.js`).
- `logs/` — анализатор логов: поток строк в терминале, закреплённый разбор строки по полям, живой анализ вставленного лога тем же алгоритмом, что на Python (`logs/analyze.js`).
- `habits/` — трекер привычек: календарь серий, закреплённые правила подсчёта, рабочий мини-трекер на модуле `habits/streak.js`.

## Решения
- Тем, кто просит меньше движения (`prefers-reduced-motion`), страница отдаётся готовой, без анимаций и закреплений.
- На узких экранах закрепления и горизонтальная лента отключаются, карточки идут столбиком (`gsap.matchMedia`).
- Список проектов лежит в одном файле `src/projects.js`.

## Запуск
```
npm install
npm run dev      # разработка
npm run build    # сборка в dist/
```
Публикация на GitHub Pages настроена в `.github/workflows/pages.yml`.
