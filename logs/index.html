Читает access-логи и показывает главное

Сколько было запросов, какая доля ошибок 4xx и 5xx, какие страницы и какие IP самые частые. Файл читается построчно, поэтому большие логи не забивают память.

      Что стоит знать
      
  
      
    
      Запуск
      python log_analyzer.py access.log --top 10. Нужен Python 3.9 или новее, внешние библиотеки не требуются.
      
    
      Устойчивость
      Битые строки пропускаются, файл читается построчно и с заменой нечитаемых символов, поэтому большой или грязный лог не роняет программу.
      
    
      Проверка
      Тесты на unittest проверяют подсчёт, проценты, отбрасывание query-строки и пустой ввод.
      
  
      

      


      
  
      Python 3.9+, unittest.
